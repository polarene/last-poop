# Ultima Cacca

Mini client-only webapp to record the date of Susanna’s last poop.

Live demo: https://polarene.github.io/last-poop/

## Install on phone

### Android (Chrome / Edge)
- Open the URL in Chrome or Edge.
- Menu ⋮ → Install app / Add to Home screen.

### Android (Firefox)
- Menu ⋮ → Add to Home screen.
- Note: Firefox may create a shortcut (not a standalone "installed app") and on some launchers it may not appear as an app.

### iPhone (Safari)
- Open the URL in Safari.
- Share → Add to Home Screen.
